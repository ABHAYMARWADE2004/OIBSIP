# OIBSIP
Oasis Infobyte Internship Projects - Data Science

## About The Internship

This Repository Contains the Projects Completed As part Of The Oasis Infobyte Data Science Internship. The Projects Demonstrate practical Applications of Data Analysis, Data Visualization And Machine Learning Using Python.

## Projects

### Task 1 — Iris Flower Classification

A Machine Learning Classification Project That Predicts The Species Of Iris flowers Using Their Sepal And Petal Measurements.

**Tech Stack:** Python, Pandas, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook

**Key Work:**

* Exploratory Data Analysis
* Data Visualization
* Classification Models
* Model Evaluation
* Confusion Matrix Analysis

[View Task 1 Project](./DataScience-Task1-IrisFlowerClassification)

### Task 2 — Unemployment Analysis

An Exploratory Data Analysis Project Focused On Unemployment Tends Across Different Regions And Time Periods, Including The Impact Of COVID-19.

**Tech Stack:** Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook

**Key Work:**

* Data Cleaning
* Regional Analysis
* Monthly Trend Analysis
* COVID-19 Impact Analysis
* Correlation Analysis
* Data Visualization

[View Task 2 Project](./DataScience-Task2-UnemploymentAnalysis)

### Task 3 — Sales Prediction Using Python

A Regression Project That Predicts Product Sales Based On advertising Expenditure Across TV, Radio, And Newspaper Channels.

**Tech Stack:** Python, Pandas, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook

**Key Work:**

* Exploratory Data Analysis
* Correlation Analysis
* Linear Regression
* Random Forest Regression
* Model Evaluation
* Residual Analysis
* Feature Importance

[View Task 3 Project](./Data-Science-Task-3-Sales-Prediction)
